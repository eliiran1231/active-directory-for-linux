## The three labels

| Label | Conservative rule |
| --- | --- |
| **not implemented** | Type absent, only a compatibility shell, or no usable core behavior on the target Linux platform. Notes distinguish these cases explicitly. At this baseline only the last case applies: Windows ACL implementations cannot execute on Linux. |
| **mostly implemented** | Substantial member implementation exists, but known member/platform exceptions or incomplete runtime evidence prevent a whole-type parity claim. This is not a numerical “more than 50%” assertion. Any minimal or throwing members remain named in the row. Implemented-but-untested stays here. |
| **mastered** | Parity actually verified within the row's explicitly bounded contract at this baseline, with reproducible evidence and no known gap within that scope. Currently reserved for enum names, numeric values/aliases, underlying integer type, FlagsAttribute and surface metadata. It does not imply that all operations consuming those constants work. Never exhaustive correctness or production certification. |

For every non-enum, the table combines source inspection with **S** (current declaration evidence) and named existing behavioral tests. A linked test proves that a comparison exists; **it does not mean it ran in this reporting session or that every overload is covered**. Unlisted behaviors remain unverified. “No missing member” means no unallowlisted declared surface difference, not no behavioral gap. Every runtime row still needs a current Windows/AD oracle run and Linux-to-real-AD validation where it uses a server.
